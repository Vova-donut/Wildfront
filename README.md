# Gameplay

Wildfront is a multiplayer strategy game inspired by real-time deck builders while introducing its own gameplay mechanics.

Players build a deck before the match and use energy to deploy units onto the battlefield. Every unit has unique abilities, strengths, and weaknesses, allowing for different strategies and playstyles.

The goal is simple:

Destroy your opponent's base before they destroy yours.

- 🃏 Deck-building system with energy management
